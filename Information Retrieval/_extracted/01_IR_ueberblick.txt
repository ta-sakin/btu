Implementierung: Invertierte Listen

n   Grundidee:
    n   Die normale Darstellung ist:
               Das Dokument wird mit allen in ihm vorkommenden
                                                           :



                    Wörtern gemeinsam abgespeichert.
    n   Die Suche geht aber nicht von den Dokumenten, sondern von
        den Wörtern aus!
    n   Also invertiert man die Verwaltung:
                Man speichert zu jedem Wort alle Dokumente ab,
                          die dieses Wort enthalten.
    n   Dazu wird zu jedem Wort eine Liste der Dokumente verwaltet, die
        dieses Wort enthalten:
                               die invertierte Liste

Evaluierung von IR-Systemen
n   Wie kann man die Qualität des Ergebnisses messen?
n   Annahme:
    n   Für eine gegebene Anfrage kann für jedes Objekt eindeutig entschieden
        werden ob es relevant oder nicht relevant ist.
n   Qualität des Ergebnisses
    n   Wie vollständig ist das Ergebnis?
        n   Anteil der gefundenen relevanten Dokumente an der Gesamtzahl der
            relevanten Dokumente
        n   50 relevante gefunden; 100 relevante insgesamt ⇒ Recall = 50 %
    n   Wie genau ist das Ergebnis? Enthält es nur relevante Einträge?
        n   Anteil der relevanten Dokumente im Ergebnis
        n   50 relevante gefunden; 75 insgesamt im Ergebnis ⇒ Precision = 67 %

Berechnung der Qualität
                                               R(q)                          -




             R( p) = ε + (1 − ε )⋅ ∑
                                  ( q , p ) outlinks ( q )



n R(p) = PageRank der Seite p

n ε = Parameter zwischen 0,1 und 0,2

n (q,p) = Seiten q mit Link zu Seite p

n outlinks(q) = Zahl der ausgehenden Links von Seite q



n Werte werden in einem iterativen Verfahren mit 5 bis 50
  Iterationen berechnet

Probleme von PageRank
n   Es erfolgt keine thematische Gewichtung der Links
    n   eigentlich könnten Links nach der thematischen Relevanz der
        verweisenden Seite gewichtet werden
n   Die Zahl der Links ist auch vom „Alter“ einer Seite abhängig
n   Es gibt zahlreiche weitere Kriterien für Qualität. Z.B.:
    n   Aktualität (z.B. über Änderungsdatum)
    n   Verfügbarkeit
    n   Informationsgehalt (Anzahl der Fachbegriffe / Wörter im Text)
    n   Popularität (z.B. über PageRank)
    n   Autorität (z.B. über manuelle Bewertungen)
    n   Kohäsion (inhaltliche Dichte à Nähe der verwendeten Begriffe)
n   Wie verrechnet man „Qualität“ und inhaltliche Relevanz?
