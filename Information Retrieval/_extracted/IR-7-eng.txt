Clique technique as generating non-hierarchical algorithm

        Each element of a cluster has similarity over a given threshold to
        every other element of the cluster
        Maximum clusters (cliques) are searched for
        Problems:
           ▶ an element can belong to several clusters
           ▶ cluster can contain only one element
           ▶ expensive calculation

Star technique as generating non-hierarchical algorithm

        Differentiation of satellite and cluster nodes
        Cluster node forms cluster with satellite nodes being more similar to
        cluster node than a threshold
        One element can appear in several clusters
        Quadratic costs

Reallocation technique as updating, non-hierarchical
algorithm


        Assignment of new element to the best cluster
           ▶ centroid (artificial average element) is managed for each cluster
           ▶ calculation of similarity to each centroid
           ▶ assignment to the most similar centroid
           ▶ recalculation of the centroids
           ▶ reassignment of all elements regarding new centroid
           ▶ centroids must then be adjusted again ...


        Repeat until stability achieved

Hierarchical clustering approaches



        Variants
           ▶   agglomerative algorithms: successive merging of single element clusters
           ▶   dividing algorithms: successive decomposition of N-element clusters
               into smaller clusters
        Advantage: relatively low computational effort, since number of
        cluster variants is reduced step by step
        Disadvantage: once a decision have been made, it cannot be revised

General agglomerative algorithm


Basis: similarity matrix
    1   Start with N one-element clusters (numbered accordingly)
    2   Search for pair (x, y ) with highest similarity
    3   Merge x and y :
           1   merge the columns and rows of x and y
           2   new value is maximum for single link (analog for the other algorithms)
           3   new cluster gets smaller number from the original clusters
    4   Steps are repeated N − 1 times

Information visualization tasks
  Task                                Description
  Overview                            Give an overview of the entire collection.
  Zoom                                Display the elements of current interest enlarged
                                      (in more detail).
  Filter                              Hide elements that are not currently of interest.
  Details-on-Demand                   Allow to select an element or a group and show the
                                      related detailed information.
  Relate                              Show the connections and links between the ele-
                                      ments (e.g. content references or citations).
  History                             The previous actions should be saved in order to
                                      perform operations such as Undo, Replay or proac-
                                      tive refinement.
