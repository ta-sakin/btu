6.1 Klassifikation

 Klassifikation: Strukturierung einer schwer
  überschaubaren Objektmenge (SQL: group by)
 Definition nach Gablers Wirtschaftsinformatik-Lexikon:

  „Klassifizierung, Klassifikation, Abstraktionskonzept, das zu einer
  Einteilung von Dingen und Begriffen führt, die durch gemeinsame
  Merkmale miteinander verbunden sind. Sowohl aus
  wissenschaftlicher als auch aus praktischer Sicht dient die
  Klassifizierung zur Erhöhung der Überschaubarkeit eines beliebigen
  Arbeitsbereichs.

Die Dezimalklassifikation

 Universal Decimal Classification UDC
 Vereinheitlichung im Bibliothekswesen
 1876 vom amerikanische Bibliothekar Malvil Dewey
  (1851-1931) entwickelt
 Jede Grundwissenschaft identifiziert durch eine Ziffer,
  etwa 0 für Allgemeines, 1 für Philosophie und
  Psychologie
 Untergruppen identifiziert durch nächste Ziffer u.s.w.

Clique-Technik als erzeugendes
nichthierarchisches Verfahren


 Jedes Element eines Clusters hat Ähnlichkeit über
  Schwellenwert zu jedem anderen Element des Clusters
 Maximale Cluster (Cliquen) werden gesucht
 Probleme:
     Ein Element kann mehreren Clustern angehören
     Cluster kann nur ein Element enthalten
     Aufwändige Berechnung

Reallokationstechnik als
aktualisierendes, nichthier. Verf.
 Zuordnung neues Element zum besten Cluster

     Neuzuordnung aller Elemente bzgl. neuem Zentroid
     Zentroide müssen dann wieder angepasst werden ...
 Wiederholung bis Stabilität erreicht
 Einsatz etwa nach Star-Technik

Hierarchische Ansätze zur Cluster-
Bildung
 Varianten
     Agglomerative Verfahren: sukzessives Verschmelzen
      einelementiger Cluster
     Teilende Verfahren: sukzessive Zerlegung
      N-elementiger Cluster in kleinere Cluster
 Vorteil: relativ geringer Berechnungsaufwand, da
  Cluster-Variantenanzahl schrittweise reduziert wird
 Nachteil: einmal getroffene Entscheidungen können
  nicht mehr revidiert werden

Single Link

 Cluster mit größter Ähnlichkeit werden
  zusammengefasst
 Ähnlichkeit zwischen Clustern als maximale Ähnlichkeit
  zwischen ihren Elementen


 Nachteil: große Cluster tendieren zur Vergrößerung

Complete Link

 Cluster mit größter Ähnlichkeit werden
  zusammengefasst
 Ähnlichkeit zwischen Clustern als minimale Ähnlichkeit
  zwischen ihren Elementen


 kleine Cluster werden bei Verschmelzung bevorzugt

Average Link

  zusammengefasst
 Ähnlichkeit zwischen Clustern als durchschnittliche
  Ähnlichkeit zwischen ihren Elementen

Ward‘s Methode

 Cluster mit kleinster Fehlersumme werden
  verschmolzen
 Fehlersumme ist Quadrate der einzelnen Euklidschen
  Distanzen der Cluster-Elemente
 Vorteil: homogene Cluster und symmetrische Cluster-
  Hierarchie
 Nachteil: hoher Berechnungsaufwand

Allgemeiner Algorithmus für
agglomerative Verfahren
Grundlage: Ähnlichkeitsmatrix
1.        Start mit N einelementigen Clustern
          (entspr. durchnummeriert)
2.        Suche nach Paar (x,y) mit höchster Ähnlichkeit
3.        Verschmelzen von x und y:
     1.     Verschmelzen der Spalten und Zeilen von x und y
     2.     Neuer Wert ist Maximum bei Single Link
            (analog für die anderen Verfahren)
     3.     Neuer Cluster bekommt kleinere Nummer der Ursprungscluster
4.        Schritte werden N-1 oft wiederholt
